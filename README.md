# 多语言随机字符生成器

一个使用原生 HTML、CSS 和 JavaScript 编写的单页工具，用于生成指定长度、语言比例和换行格式的随机测试文本。无需安装依赖或构建，可直接在浏览器中使用。

> 生成的是从预设字符池随机抽取的字符，不是具有语义的句子。适合输入长度、混合语言、特殊符号和文本展示等测试场景。

## 快速开始

下载项目后，使用现代浏览器打开 `index.html`。

也可以在 VS Code 中打开项目，安装 Live Server 扩展，右键 `index.html` 选择 **Open with Live Server**，通过本地服务预览和调试。

1. 填写目标字符长度。
2. 勾选语言或特殊符号，按需调整占比。
3. 可选：填写需要置于结果最前面的指定内容。
4. 可选：将“是否换行”设为“是”，填写每行字符数。
5. 点击“生成”，查看结果、字符长度和分配统计。
6. 可直接编辑结果，再点击“复制”获取当前文本。

## 功能

### 长度与字符计数

- 目标长度必须为 **1～1,000,000** 之间的整数，默认值为 **100**。
- 按 Unicode 码点计数，不按字节或 JavaScript UTF-16 编码单元计数。
- 空格计入长度；回车和换行符（`\r`、`\n`）不计入长度，包括指定内容及手动编辑的结果中的换行。
- 单个普通汉字、英文字母或普通独立 emoji 通常计为 1；组合 emoji、组合附加符等可能包含多个码点，与视觉上看到的字符数量不同。

### 语言与特殊符号

支持以下 9 种语言和特殊符号，可单选或多选：

| 类型 | 选项 |
| --- | --- |
| 中文 | 简体中文、繁体中文 |
| 拉丁字母语言 | 英语、越南语、德语 |
| 从右向左书写的语言 | 波斯语、阿拉伯语 |
| 西里尔字母语言 | 俄语、乌克兰语 |
| 符号 | 特殊符号 |

字符池为项目内置的有限集合，并不覆盖各语言的全部字符。不同语言的字符池可能有相同字符，分配统计表示从各字符池抽取的数量，不是对结果文本进行语言识别后的数量。

### 占比调整

- 仅选中一项时，占比固定为 **100%**。
- 勾选或取消勾选后，所有已选项重新均分 **100%**，原手动比例会被重新分配。
- 支持通过滑块或数字输入框调整比例，范围为 **0～100%**，使用整数百分比。
- 手动调整一项时，其余已选项按原比例分配剩余百分比；其余项原比例均为 0 时，均分剩余比例。
- 未选项占比为 0，调整控件禁用。
- “全选”选中全部 10 项，各占 10%；“反选”切换全部勾选状态；“清空”取消全部勾选。批量操作后重新均分比例。

均分无法整除时，将剩余百分点补给页面排列靠后的选项。例如，选中简体中文、英语和越南语时，比例为 **33%、33%、34%**。

### 生成数量的分配规则

先扣除指定内容占用的长度，再按占比分配随机生成部分：

```text
剩余长度 = 目标长度 − 指定内容长度
某项理论数量 = 剩余长度 × 该项占比 ÷ 100
```

为保证总长度准确，数量取整采用**最大余数法**：先对每项理论数量向下取整，再按小数部分从大到小补齐剩余字符。小数部分相同时，优先补给页面排列靠后的选项。

| 目标长度 | 指定内容 | 所选比例 | 实际分配 |
| --- | --- | --- | --- |
| 100 | 无 | 英语 100% | 英语 100 个 |
| 200 | 无 | 简体中文 33%、英语 33%、越南语 34% | 66、66、68 个 |
| 100 | 中国 | 英语 20%、越南语 80% | 指定内容 2 个，英语 20 个，越南语 78 个 |

随机生成部分会打散顺序，指定内容始终置于最前面。单项占比为 0 时，该项不生成字符。

### 指定内容

- 可填写固定前缀、测试标记或其他文本。
- 指定内容占用总长度，不参与语言比例分配。
- 超过目标长度时，提示错误，不覆盖已有结果。
- 恰好等于目标长度时，结果仅包含指定内容，此时可以不选择语言或特殊符号。
- 还有剩余长度时，必须至少选择一种语言或特殊符号。

### 按每行字符数换行

- 默认选择“否”，“每行字符”输入框禁用。
- 选择“是”后可编辑，仅接受正整数；留空则不执行自动换行。
- 从“是”切换为“否”时，自动清空每行字符数。
- 点击“生成”时，对包含指定内容的完整文本执行换行；指定内容也可能被切分到多行。
- 无法整除时，剩余字符放在最后一行，不添加末尾换行。
- 指定内容已有换行时，保留原换行，并对每个已有行分别按设定长度切分。
- 自动换行只在生成时执行，手动编辑结果不会自动重新排版。

例如：

| 目标长度 | 每行字符 | 结果 |
| --- | --- | --- |
| 100 | 10 | 10 行，每行 10 个字符 |
| 23 | 10 | 3 行，分别为 10、10、3 个字符 |
| 10 | 20 | 1 行，共 10 个字符 |

上述示例假定指定内容不包含已有换行。浏览器还可能因输入框宽度进行视觉折行，这与文本中插入的换行符不同。

### 编辑与复制

- 生成结果可直接输入、删除或粘贴，字符长度实时更新。
- 手动编辑后，原始语言分配统计会清除，避免与当前内容不符。
- “复制”复制当前结果，包括手动修改和换行符。
- 结果为空时，复制按钮禁用。
- 再次生成会覆盖当前结果。
- 优先使用浏览器 Clipboard API；不可用时尝试兼容复制方式。如果自动复制失败，会选中结果，可按 `Ctrl+C` 或 macOS 的 `⌘C` 复制。使用 HTTPS 或 localhost 有利于剪贴板功能正常工作。

### 清除与重置

字符长度、指定内容、生成结果输入框均提供独立的 **×** 清除按钮，仅清空对应内容，并将焦点移回对应输入框。清除生成结果时，还会将字符统计归零、清除分配统计并禁用复制。

“语言与符号”旁的“清空”仅取消勾选，不清除输入内容或已有结果。

点击顶部“重置”恢复以下初始状态：

| 设置 | 初始值 |
| --- | --- |
| 字符长度 | 100 |
| 语言与符号 | 仅选中简体中文，占比 100% |
| 指定内容 | 空 |
| 是否换行 | 否 |
| 每行字符 | 空，且禁用 |
| 生成结果 | 空 |
| 实际字符长度 | 0 |
| 复制按钮 | 禁用 |
| 提示与分配统计 | 清空 |

## 技术与数据处理

- 使用原生 HTML、CSS、JavaScript，无第三方运行依赖。
- 使用 `crypto.getRandomValues()` 抽取随机数，通过拒绝采样避免取模偏差。
- 界面适配桌面和窄屏，结果区支持从右向左书写的文本。
- 生成与编辑在浏览器本地完成，当前实现不发送网络请求，也不保存输入或结果；刷新页面后不保留本次内容。
- 较大的目标长度会占用更多内存和页面处理时间。

## 验证范围

开发期间已通过 Node 模拟 DOM 事件检查部分交互逻辑，包括批量选择、编辑计数与复制、清除与重置，以及换行的整除、余数和校验场景。项目目前没有持久化的自动化测试套件，尚未完成跨浏览器与移动设备的完整回归验证。
